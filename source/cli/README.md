# cli

`import xtb.cli;` provides a typed command-line parser derived from D structs and
attributes. It supports nested commands, options and positionals, aliases,
defaults, reusable flattened groups, and custom value parsing.

See the [CLI guide](docs/guide.md) or the
[`cli`](../../examples/cli_demo.d) and
[`cli-nested`](../../examples/cli_nested_demo.d) examples.
